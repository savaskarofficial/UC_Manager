# UC Manager

Android file manager and APK editor developed by Sharodshahi Al-Amin, owner of Undercover IT Firm. Browse files in two panes, edit archives and APKs, inspect DEX and native libraries, and manage signing keys.

Requires Android 8.0 or later. APKs are signed with UITF. Find APKs and checksums on the [Releases](../../releases) page.
